----------------------------------------------------------------
  4. LAYOUT & SPACING
----------------------------------------------------------------

  Canvas orientation  :  Landscape on desktop (full viewport)
                         Portrait on mobile (400px wide, scaled)
  Announcement bar    :  Fixed top, 28px height, z-index 200
  Panel padding       :  GH × 0.024 (inner top/bottom)
  Element gap         :  GH × 0.016 (between stacked elements)
  Side padding        :  14–16px from panel edge
  Max panel width     :  380px (portrait) / 520px (leaderboard)


----------------------------------------------------------------
  5. EFFECTS & ANIMATION
----------------------------------------------------------------

  Glow / Shadow
  ─────────────
  Panel glow     :  shadowColor #ffd700,  shadowBlur 16
  Title glow     :  shadowColor [countdown color], shadowBlur 40
  Verified badge :  shadowColor rgba(29,161,242,0.5), shadowBlur 12
  Coin pulse     :  scale = 1 + sin(frame × 0.08) × 0.07

  Particle Effects
  ────────────────
  Coin collect   :  10 gold sparks (#ffd700), radial burst
  Death          :  22 pink sparks (#ff6688), radial burst
  Flap           :  5 pink sparks (#ffccdd), upward
  Life           :  fade out over ~35 frames, gravity 0.12

  Float Texts
  ───────────
  +10            :  white, floats up, fades over 1.4s
  +25 $BTH       :  gold (#ffd700), floats up, fades over 1.4s

  Countdown
  ─────────
  Scale          :  starts 1.6×, shrinks to 1.0× over 1 second
  Transition     :  one number per second, 4 steps (3,2,1,GO!)
  Shadow blur    :  40px matching countdown color

  Background
  ──────────
  Scroll speed   :  GW ÷ 140 pixels per frame
  Cloud parallax :  0.13× – 0.24× scroll speed (layered depth)
  Countdown idle :  0.4× scroll speed (slow drift)

  Screen Shake
  ────────────
  Trigger        :  On death, shake = 14
  Decay          :  shake × 0.78 per frame
  Direction      :  random ± shake pixels (X and Y)


----------------------------------------------------------------
  6. AUDIO (Web Audio API — procedural, no files)
----------------------------------------------------------------

  Flap sound     :  Sine wave, 320Hz → 560Hz, 80ms, vol 0.18
  Coin collect   :  Sine 880Hz → 1200Hz (60ms) +
                    Sine 1100Hz → 900Hz (120ms), vol 0.22
  Pipe pass      :  Square wave, 440Hz → 660Hz, 60ms, vol 0.08
  Death          :  Noise burst bandpass 900→80Hz (350ms) +
                    Sawtooth 160→60Hz (400ms), vol 0.45
  Game start     :  Sine 440 → 550 → 660 → 880Hz cascade
  Countdown 3    :  Square 220Hz, 120ms
  Countdown 2    :  Square 330Hz, 120ms
  Countdown 1    :  Square 440Hz, 120ms
  GO!            :  Sine 880→1200Hz + 1200→880Hz chime


----------------------------------------------------------------
  7. GAME CONSTANTS
----------------------------------------------------------------

  Gravity        :  GH × 0.00063  per frame
  Flap force     :  -(GH × 0.013)
  Scroll speed   :  GW ÷ 140  px/frame
  Pipe gap       :  GH × 0.275
  Pipe width     :  GH × 0.092
  Cap height     :  pipe_width × 0.50
  Cap overhang   :  pipe_width × 0.055  each side
  Ground height  :  GH × 0.115
  Min pipe topH  :  max(CAP_H + 18, GH × 0.16)
  Hat width      :  GH × 0.115
  Hat height     :  hat_width × 0.80
  Pipe interval  :  1900ms
  Daily limit    :  10 plays per day (resets at midnight)
  Score / pipe   :  +10 points
  Score / coin   :  +25 points
  $BTH rate      :  1 $BTH per 100 score points


----------------------------------------------------------------
  8. SCORING SYSTEM
----------------------------------------------------------------

  Pass a pipe gap    →  +10 points
  Collect a coin     →  +25 points
  100 points         →  1 $BTH coin (V1: practice only)
  High score         →  saved locally per browser session
  Global leaderboard →  top 10 per unique username (Supabase)
  Daily cap          →  10 games per day, resets at midnight
